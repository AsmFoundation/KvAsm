# h2spec v2.6.0 cases that fail against kvnode linked with nghttp2 1.70.0.
# Format: "<package> | <case>", exactly as in h2spec's JUnit output.
#
# run.sh (phase 6) fails the build on any failure or skip NOT listed here,
# and prints a note when a listed case starts passing (then delete its line).
# None of these is kvnode code; all are nghttp2 library behavior:
#
#  * http2/5.1.1 — nghttp2 itself: the reference server nghttpd fails it too
#    (measured with Debian's nghttpd 1.64.0: 145/146 passed).
#  * everything else — nghttp2 v1.65.0 (2025-03-02) removed RFC 7540 stream
#    priorities (nghttp2 PR #2287) and closed-stream tracking (PR #2289).
#    PRIORITY frames are no longer validated, and frames arriving on an
#    already-closed stream are ignored instead of raising STREAM_CLOSED;
#    the window-overflow case on a closed stream ends the connection instead
#    of the stream. The same server code linked with nghttp2 1.64.0 passes
#    all seven. Staying on <= 1.68.0 is not an option: CVE-2026-27135 (high,
#    remote assertion-failure DoS via nghttp2_session_terminate_session,
#    which kvnode calls for idle timeouts) is fixed in 1.68.1.
#  * "half closed (remote): Sends a HEADERS frame" — the same removal, as a
#    race: the second HEADERS raises STREAM_CLOSED only if it arrives in the
#    same read as the request; if kvnode has already answered (stream
#    closed), nghttp2 ignores it. Measured 1 failure in 8 runs, so run.sh
#    may print it as "now passing" — expected, keep the line.
#
# The native engine (KVNODE_H2_ENGINE=native, h2n.asm) has its own, empty
# baseline: h2spec-known-failures-native.txt (146/146).
#
# Details and the decision records: docs/adr/0002-http2-library-nghttp2.md,
# docs/adr/0007-native-http2-engine.md.
